# API Neural Explorer -> API Neural Network: Implementation Audit

**Audit Date**: October 2026  
**Auditor**: Senior AI Systems Engineer & TypeScript Specialist  
**Project**: `api-neural-explorer`  

---

## 1. Executive Summary

API Neural Explorer was initially constructed as a responsive frontend demonstration illustrating a 10-stage neural ingestion and RAG pipeline. While the UI design, responsive layouts, theme switching, and interactive canvas components (@xyflow/react, Lucide icons, Hyperspeed Three.js shaders) are functional and well-structured, the underlying pipeline logic relies almost entirely on simulated asynchronous delays (`setTimeout`), pseudo-random calculations (`Math.random`), character-code hashing masquerading as `all-MiniLM-L6-v2` embeddings, hardcoded heuristic boosts, simulated MCP tool calls, and silent fallbacks to static demo data on API fetch failures.

The objective of this project transformation is to preserve the frontend layout and UI components while replacing the simulated modules with a genuine, production-oriented, and observable **API Neural Network** platform.

## 3. Detailed Audit of Mocked & Simulated Features

### 3.1. API Ingestion (`src/services/apiService.ts`)
- **Silent Mock Fallback**: When fetching any non-sample URL, if the browser encounters a CORS error, network failure, or `example.com` domain, lines 232–248 catch the exception and silently return `SAMPLE_PRODUCTS_DATA` labeled with HTTP 200 `OK (Demo Mode Fallback)`. The user is never informed that their live endpoint failed.
- **Artificial Delay**: Sample APIs are fetched with a hardcoded `await new Promise(r => setTimeout(r, 180))` rather than real response latency.
- **Ambiguous Array Extraction**: Object normalization naively searches for the first array key without explicit user control, path preservation, or schema inspection.

### 3.2. NLP & Tokenization (`src/services/nlpService.ts`)
- **Static Stopwords and Hardcoded Stemming**: `LEMMA_MAP` contains 16 static words (`running`, `shoes`, `designed`, `headphones`, etc.) tailored solely to the sample products.
- **Fixed Sample Text**: If no description exists, it falls back to hardcoded text `"Running shoes designed for everyday comfort"`.
- **String Concat Chunks**: Chunks are generated by simply joining object entries with ` | `, without field path tracking, boundary detection, token count bounds, or overlap handling.

### 3.3. Embeddings & Vector Operations (`src/services/vectorService.ts`)
- **Pseudo-Random Vector Generation (`generate384Vector`)**:
  ```typescript
  // Lines 3-15 of vectorService.ts
  for (let i = 0; i < normalized.length; i++) {
    const charCode = normalized.charCodeAt(i);
    const pos = (charCode * (i + 1) * 31) % 384;
    vector[pos] += 0.15;
  }
  ```
  This character position hash distributes character weights across 384 indices. It is **not** a neural embedding, encodes no semantic relationships, and is falsely labeled `model: 'all-MiniLM-L6-v2'`.
- **Fabricated Similarity Scores (`searchVectorDatabase`)**:
  ```typescript
  // Lines 70-85 of vectorService.ts
  if (queryLower.includes('10000') || queryLower.includes('10,000')) {
    if (chunk.price && chunk.price > 10000) similarity = Math.max(similarity, 0.88);
  }
  const baseSim = Number((0.75 + Math.random() * 0.18).toFixed(2));
  const finalSim = Math.min(0.96, Math.max(similarity, baseSim));
  ```
  Similarity scores are randomly generated between 0.75 and 0.96 using `Math.random() * 0.18`, with hardcoded heuristic overrides for specific words ("10000", "shoes", "electronics").
- **Forced Output Slicing**: The search function always returns `slice(0, 4)` matches, even when the query has zero semantic relevance to the indexed documents.

### 3.4. RAG & Query Processing (`src/services/ragService.ts`)
- **Simulated Delays**: Lines 12, 19, 22, 25 use chained `setTimeout` delays to mimic server processing.
- **Template-Based Hardcoded Answers**:
  ```typescript
  if (queryLower.includes('10000') ...) { ... }
  else if (queryLower.includes('shoe') ...) { ... }
  else if (queryLower.includes('user') ...) { ... }
  ```
  No LLM is called; queries matching predetermined keywords return hardcoded string templates. Queries outside the keywords return a generic canned message.

### 3.5. Model Context Protocol (`src/services/mcpService.ts`)
- **Faked Tool Calls**: `executeMcpTool()` creates a synthetic `setTimeout(..., 30 + Math.random() * 50)` delay and resolves with `{ status: 'SUCCESS', resultCount: params.limit || 4 }`. Neither an MCP server nor actual tools exist.

### 3.6. Pipeline Execution (`src/App.tsx`)
- In `runPipelineProcess()`, stages `json_parser`, `nlp`, `tokenizer`, `chunker`, `embedding`, `vector_db`, `mcp_server`, `rag`, and `llm` are stepped through via sequential `setTimeout` promises (180ms - 300ms) with hardcoded logs. The embedding engine is passed only a single sample text rather than embedding all chunks.

## 4. Security & Data Flow Issues

1. **CORS Vulnerability & Lack of Proxy Option**: Browser fetches direct to arbitrary third-party endpoints will be blocked by CORS unless endpoints have open wildcard headers. The previous implementation masked this by falling back to sample products.
2. **SSRF & Loopback Risk**: Live URLs are not validated for dangerous private network ranges (`127.0.0.1`, `169.254.169.254`, `localhost`, RFC1918 addresses).
3. **Cross-Source Contamination**: In-memory state did not namespace or flush vectors when connecting to a new URL, potentially leaking search matches across distinct API sources.
4. **Lack of Persistence**: Reloading the page clears all pipeline state, indexed data, and trace history.
5. **No Secret Protection**: API keys cannot currently be entered or stored securely.

1. `src/types/index.ts`: Add `DataSourceMode` ('live' | 'demo'), extend `RagChunk` with `fieldPaths`, `sourceUrl`, `sourceId`, add `EmbeddingProviderConfig`, `LlmProviderConfig`, and `ApiOperation`.
2. `src/services/apiService.ts`: Implement robust live HTTP ingestion with URL validation, timeout, size limits, explicit demo mode, and transparent CORS/network error reporting.

4. `src/services/vectorService.ts`: Replace character hash with real embedding provider interface and genuine cosine similarity.
5. `src/services/ragService.ts`: Ground answers strictly on retrieved records, eliminate hardcoded keyword branches, support transparent retrieval-only synthesis or external LLMs.
